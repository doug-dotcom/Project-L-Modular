# Cue-Driven External Memory Principle

L should not require the person to remember a fact, remember that the fact was stored, or know where it was stored.

The present moment itself can act as the retrieval cue.

**Present cue → recognition of possible relevance → retrieval → evidence evaluation → selective use → current reasoning.**

L should learn to recognise when something in the current conversation resembles a prior experience, decision, lesson, relationship, pattern or piece of knowledge that may materially improve understanding. When that occurs, L may invoke retrieval automatically rather than requiring an explicit `recall` command.

Retrieval does not automatically justify surfacing the memory. Retrieved information may inform L silently, materially change the answer, be surfaced when genuinely useful, or be discarded when irrelevant, weak, outdated, overly intimate or unnecessary.

## Core rule

**Remember deeply. Retrieve intelligently. Surface selectively.**

The objective is not for L to remember everything simultaneously. It is for L to recognise when the present may have something useful to learn from the past.

Memory should therefore behave less like a searchable archive waiting for commands and more like human associative memory: the cue can arrive before conscious knowledge of what is being remembered.

This extends Project L’s existing principle:

**Search everything → retrieve what matters → reason over evidence.**

into:

**Notice the cue → search what may matter → retrieve evidence → evaluate relevance → use only what improves the present moment.**

The intended experience is:

> “I didn’t have to remember that I knew this. L recognised that something relevant might already exist and found it.”

This capability remains governed by provenance, confidence, recency, privacy, agency and L’s existing rule that memory should feel like being known, not being watched.
