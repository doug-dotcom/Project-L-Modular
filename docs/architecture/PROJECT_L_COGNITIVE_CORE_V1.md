# Project L Cognitive Core v1

Project L is one companion with a governed, model-agnostic cognitive system.
The language model supplies language and bounded inference; Project L supplies
identity, memory, evidence, reasoning structure, continuity, learning policy,
principles and constitutional control.

## Live cognitive path

1. L receives Doug's request and remains the only user-facing voice.
2. Rhee retrieves identity, continuity, learning and relevant evidence.
3. The capability router invokes deterministic services only when required.
4. Mary activates only for longitudinal questions and requires at least two
   traceable observations before allowing a pattern claim.
5. Quinn supplies relevant, versioned principles with advisory authority only.
6. RIKE activates for complex reasoning and returns a bounded packet containing
   assumptions, hypotheses, conflicts, conclusion, calibrated confidence,
   uncertainty, recommended action and a concise inspectable rationale.
7. Agency and drift guardrails check the packet before L synthesises a response.

## Durable-memory path

1. Raw and live short-term memory preserve conversation continuity.
2. The promotion gate rejects questions, instructions, assistant text and noise.
3. Carol v5 normalises content, subjects, domains and source provenance.
4. Sara v2 applies the governance decision, salience and importance.
5. Mary v4 records only an observation-level pattern candidate when signalled.
6. Episodic memories and identity anchors remain specialised governed services.
7. Relevant recall caches are invalidated only after successful writes.

## Learning policy

The Learning Engine never treats L's own answer as proof. Only explicit
Doug-authored learning observations or later observed outcomes can become learning
candidates. Existing independent-source, validation, contradiction and confidence
thresholds determine whether a candidate may be applied.
