# Layer 132 — saved-status search

Saved-answer search now includes the fixed status heading as well as question and displayed answer text. Searching for phrases such as still working, facts changed or verification failed finds the corresponding checked results. Rejected answer content remains excluded.

When search and filters hide all checked entries, the count area points to Clear filters. It also says when more tasks remain unchecked, avoiding the impression that a search covered all browser tasks. The guidance disappears when results become visible. Search does not issue requests or change check timestamps.

Validation covers case-insensitive status phrases, intersections with status filters, incomplete and complete review guidance, and Clear filters. Phone visual testing remains outstanding.
